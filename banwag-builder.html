How this works

The real Banwag was shaped in Rhino + Grasshopper — a script computed every rib and node before any bamboo was cut. These sliders drive the same kind of script: an axisymmetric onion-dome profile revolved into a 16-sided rib cage, with the cladding built as a separate skin you can toggle or set panel by panel.
