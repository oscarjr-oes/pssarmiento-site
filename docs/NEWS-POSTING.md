# Posting news — front-matter convention

News posts are Markdown files in `_posts/`, named `YYYY-MM-DD-short-slug.md` (the slug becomes the URL
`/news/short-slug/`). SEO and link previews are generated by `jekyll-seo-tag` from the front matter below.

```yaml
---
title: "Garage Sale for a Cause"            # required
date: 2026-05-19                            # required
category: "News & Events"                   # News & Events | Foundation | Projects | Newsletter
author: Name                                # optional
description: "One or two sentences, ~120–160 characters, plain text."   # REQUIRED for SEO
image: /assets/news/garage-sale-for-a-cause.jpg    # optional share image
cover: /assets/news/garage-sale-for-a-cause.jpg    # shown at top of the post
tags: [Primosa, Community]
---
```

## `description` (required)

- Shown as the Google snippet and as the text in Facebook / Viber / Messenger link previews.
- Write 1–2 plain sentences, about 120–160 characters. No Markdown or HTML.
- If omitted, the site falls back to the post's first paragraph, which is usually a poor summary.

## `image` (recommended)

- The picture used in link previews. Best: **1200×630 px JPG** (about 1.9:1), under 1 MB.
  Portrait or very large photos get cropped awkwardly or fail to load.
- Store it under `assets/news/` and use a path starting with `/`.
- If omitted, `/assets/og/default.jpg` (PS Group branded image) is used.
- Usually set it to the same file as `cover`.

## Previewing a share before announcing

After the post is live, paste its URL into the
[Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/) and click **Scrape Again**. Facebook and
Viber cache previews, so do this if you fix a description or image after first sharing.
