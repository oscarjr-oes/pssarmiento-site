{%- comment -%} Responsive for an image under assets/. Uses _data/images.json (written by scripts/optimize_images.py). Falls back to a plain when the image has no variants yet (e.g. a fresh Decap CMS upload) so nothing ever breaks. Params: src (required), alt, sizes (default 100vw), style, class, loading = lazy (default) | eager (above the fold) | hero (LCP: eager + fetchpriority=high) NOTE: the intrinsic width/height attributes are always emitted (they reserve layout space), so in `style` set width AND height explicitly, or use width:auto / height:auto, otherwise the attribute values leak into the layout. Pages also need `picture{display:contents}source{display:none}` in their CSS so the wrapper does not add a box. {%- endcomment -%} {%- assign key = include.src | remove_first: '/' -%} {%- assign meta = site.data.images[key] -%} {%- case include.loading -%} {%- when 'eager' -%}{%- assign load_attrs = 'decoding="async"' -%} {%- when 'hero' -%}{%- assign load_attrs = 'fetchpriority="high" decoding="async"' -%} {%- else -%}{%- assign load_attrs = 'loading="lazy" decoding="async"' -%} {%- endcase -%} {%- if meta -%} {%- else -%} {%- endif -%}
